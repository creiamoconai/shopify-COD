# VitaLeggera™ — Tracker Ordini COD

App web per tracciare ordini, campagne Meta Ads e KPI di VitaLeggera™.

## Funzionalità
- Dashboard KPI (CPO, risultato netto, ordini, spend)
- Tracker ordini COD con stati
- Storico campagne Meta Ads
- Grafici performance
- Esporta CSV
- Dati salvati in localStorage
